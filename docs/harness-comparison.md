# Harness comparison

The original local harness research contributed four durable ideas:

- stable task identity instead of title matching;
- an exact-event ledger and bounded watched roots for intake;
- a routing queue that can recover from unavailable destinations;
- compact, durable checkpoints rather than transcript copies.

Agent OS keeps those ideas but deliberately excludes a second hosted agent
runtime, containers, queues, secret vaults, and broad provider write authority.
Codex remains the execution environment; Agent OS owns only project routing,
durable outcomes, exact correlation, and replaceable presentation.

The source material and private pilot evidence are local research history and are
not part of the shareable product tree.
