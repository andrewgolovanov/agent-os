## ✨ Features

- **Slack-only work without repositories.** Actionable requests from named
  channels can become unassigned outcomes with a display-only channel label,
  without creating a fake project or repository route.
- **Readable Slack source cards.** A source can show a cleaned, 96-character
  excerpt from the thread's root message instead of the generic `Slack thread`
  title. Existing sources remain compatible and active sources are filled in
  gradually by bounded monitor passes.

## 🐛 Fixes

- **Correct Sparkle feeds.** Release packaging now generates the appcast from
  only the current archive, so stale local builds cannot inherit a new tag URL
  or appear in the published update feed.
- **Stable Slack reprocessing.** Re-reading the same channel or thread refreshes
  its label or short title idempotently without duplicating the source, changing
  its exact permalink identity, or enabling repository routing.
