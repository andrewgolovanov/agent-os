## ✨ Features

- **Frequently used projects can stay pinned in the native sidebar.** Agent OS
  stores an ordered local presentation preference without changing canonical
  project identity, Task Board routing, Slack mappings, or plugin behavior.
- **The app and Codex plugin can advance together safely.** Packaged Agent OS
  detects an older installed plugin, offers an explicit update action, and can
  follow stable release tags automatically after the user opts in. Failed
  installs restore the prior tag, and newer plugins are never downgraded.
- **Exact Slack channel labels reconcile with registered projects.** Automatic
  project synchronization links a channel only when its normalized name has
  one non-conflicting project owner, then attributes only unfinished work that
  is still unassigned.

## 🐛 Fixes

- **Native project synchronization now works from GUI launches with a minimal
  PATH.** Agent OS prefers the self-contained Codex executable bundled with
  Codex or ChatGPT and supplies safe standalone CLI fallback paths, preventing
  App Server status `127` from a Node wrapper whose runtime was unavailable.
- **Completed-only Slack labels no longer clutter the sidebar.** Historical
  labels remain on Done outcomes and source records, while empty label groups
  disappear after deterministic project reconciliation.
