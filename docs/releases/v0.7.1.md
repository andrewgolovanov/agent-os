## ✨ Features

- **The native sidebar now stays focused on actionable projects.** Pinned
  projects remain visible, while unpinned zero-work and completed-only projects
  stay registered but return to the sidebar only when new unfinished work is
  assigned.

## 🐛 Fixes

- **Completed-only Slack channels remain available as Labels.** Agent OS keeps
  unmapped channel navigation with a zero unfinished count instead of hiding
  historical channels after project synchronization.
- **Project pin controls no longer disturb sidebar alignment.** A compact hover
  star sits on the title line immediately left of the fixed trailing count, and
  pinned projects retain a visible filled star.
