## ✨ Features

- **Every active local Codex project can register automatically.** Agent OS now
  recognizes deterministic working directories even when they do not use Git,
  so new local-only work receives a real project and Task Board routing without
  a separate onboarding step.
- **Projects grow into repositories without losing continuity.** Adding the
  first commit and later a remote at the registered project root enriches the
  same project key, preserving its tasks, Slack mappings, and history.

## 🐛 Fixes

- **Local-only projects no longer fall back to channel labels unnecessarily.**
  Future Slack intake can route to a registered project whether or not that
  project currently has repository metadata.
- **Same-name and overlapping folders remain deterministic and safe.** Stable
  path-derived suffixes distinguish same-name roots, while ambiguous overlaps,
  duplicate origins, and transient-only worktrees are skipped without blocking
  other projects.
