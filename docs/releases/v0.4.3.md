## ✨ Features

- **More resilient Task Board tooling.** All task-targeting Agent OS MCP
  mutations share one compatibility boundary for generated identifier fields.

## 🐛 Fixes

- **Task updates no longer fail on a harmless ID field-name variation.** Agent
  OS MCP accepts `taskId`, `task_id`, or `id` for task-targeting mutations while
  keeping `taskId` as the documented canonical field.
- **Conflicting IDs remain safe.** If more than one identifier field is present
  with different values, Agent OS rejects the call before changing Task Board
  state.
