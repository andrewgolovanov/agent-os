## ✨ Features

- **Focus is organized by recency.** Current outcomes are grouped into Today,
  Yesterday, This Week, Last Week, and Earlier using the local calendar. Empty
  periods stay hidden, and the lightweight headings scroll naturally with the
  list.
- **Project context is easier to scan.** Project or Slack-label context now sits
  above each task title, while lifecycle status remains the only trailing
  signal.

## 🐛 Fixes

- **Cleaner Focus hierarchy.** Compact typography, a bounded reading measure,
  additional line spacing, and edge-to-edge separators make long mixed-project
  outcomes easier to read without card-like backing surfaces.
- **Predictable task-detail resizing.** The inspector now uses a dedicated
  resize handle with the horizontal resize cursor and an accessible adjustable
  action while retaining its bounded desktop widths.
- **Consistent titlebar separation.** The content titlebar keeps a semantic
  one-pixel border in both light and dark appearances.
