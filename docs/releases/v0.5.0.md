## ✨ Features

- **Codex projects register themselves when work starts.** The Agent OS app
  discovers eligible Git roots from active Codex task metadata, and the plugin
  registers the current repository before routing a new task. Existing project
  work no longer requires a separate onboarding step.
- **Actionable Slack bot mentions reach the normal intake flow.** The monitor
  dynamically checks visible channels without a fixed channel allowlist and
  processes a bot or app thread only when it mentions the exact current user.

## 🐛 Fixes

- **Repository-backed Slack work avoids unnecessary channel-only fallback.** A
  safely discoverable Codex repository is registered before future Slack work
  is correlated, while missing or conflicting repositories still remain
  unassigned with their stable channel labels.
- **Partial Slack scans retain safe progress.** Independent channel cursors
  resume completed channel windows after rate limiting without advancing the
  global cursor or persisting unrelated bot messages.
