## ✨ Features

- **Projects can adopt reviewed Slack work.** Project onboarding now suggests
  conservative channel-name matches, then requires a second preview with exact
  channel IDs before it stores a mapping or assigns unfinished work that has no
  project. Future signals from that channel use the registered project while
  the channel label remains visible on each task card.
- **Persistent Light and Dark appearance.** A sun/moon toolbar button switches
  the entire native app between shadcn Neutral light and dark semantic palettes
  and saves the preference for future launches. Dark remains the default.
- **More readable task details.** The resizable inspector now opens wider so
  task titles, pull-request context, goals, and current-state text wrap less
  aggressively on desktop.

## 🐛 Fixes

- **No duplicate project and channel navigation.** A mapped Slack channel stays
  on task cards for source context but no longer appears as a redundant
  top-level label beside its project. Exact channel IDs remain distinct, and
  onboarding never overwrites existing project attribution or merges tasks by
  similar text.
- **Cleaner Board scrolling.** Lifecycle columns keep their independent
  vertical scrolling and fixed headers without showing persistent scroll bars.
